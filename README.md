# Personal Finance Web API

Backend API cho ứng dụng quản lý tài chính cá nhân, xây dựng với FastAPI,
Pydantic v2, SQLAlchemy 2 và PostgreSQL.

## Chạy cục bộ

Yêu cầu Python 3.12+ và PostgreSQL 16+. Tạo database `personal_finance_db`,
sao chép `.env.example` thành `.env`, sau đó thay `SECRET_KEY` bằng một chuỗi
ngẫu nhiên đủ dài. Cài đặt và khởi tạo schema:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload
```

Tài liệu OpenAPI có tại `/docs`; endpoint kiểm tra trạng thái là `/health`.

## API hiện có

Tất cả API phiên bản 1 có tiền tố `/api/v1`.

- `POST /auth/register`, `POST /auth/login`
- `POST /auth/refresh` (refresh token được xoay vòng), `POST /auth/logout`
- `GET /users/me`
- `GET|POST /accounts`, `GET /accounts/{account_id}`
- `GET|POST /transactions`, `GET /transactions/{transaction_id}`
- `POST /imports/preview`, `POST /imports/{batch_id}/confirm` (CSV/XLSX, staged)
- `GET|POST /budgets`, `GET /budgets/{budget_id}`
- `GET|POST /recurring-transactions`, `PATCH /recurring-transactions/{id}`

Import files require `transaction_date`, `kind` (`income` or `expense`), and
`amount` columns. Optional fields are `description`, `merchant`, `category_id`,
and `subcategory_id`; category IDs must belong to the user or be system-defined.

Recurring rules are generated by an in-process APScheduler job once per minute.
Generation and balance updates share a database transaction; database row locks
and per-occurrence deduplication keep multiple API workers from double posting.
Rules pause and emit an idempotent notification when an occurrence would exceed
the account's available balance or credit limit.

Refresh token được lưu dưới dạng SHA-256 hash; mật khẩu dùng bcrypt. Các thao
tác thu/chi cập nhật số dư bằng phép cộng nguyên tử trong cùng transaction cơ
sở dữ liệu với bản ghi giao dịch. Các FK kết hợp ngăn truy cập chéo tài khoản.

Schema migration khởi tạo tạo 30 bảng, bật `btree_gist` cho ràng buộc kỳ ngân
sách không chồng lấn, và thêm các loại tiền tệ/vai trò mặc định.
